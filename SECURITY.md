# Security policy

## Supported versions

Only the latest release of Notice Board (`noticeboard`) receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report them privately, either through GitHub's
"Report a vulnerability" button on the repository's *Security* tab, or by e-mail to
**memoceylan712@gmail.com** with the subject `noticeboard security`.

Please include the Notice Board and Nextcloud versions, the steps to reproduce,
and the impact you expect. You will get an answer within a few working days;
a fix is released as a new App Store version and mentioned in `CHANGELOG.md`.
